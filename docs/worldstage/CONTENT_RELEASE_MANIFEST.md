# WorldStage content release manifest

**Purpose:** prevent placeholders, invented facts, unauthorized client material, or unlicensed assets from being promoted into production.

## Status vocabulary

- `MISSING` — required production content has not been supplied.
- `SUPPLIED` — asset/fact was provided but rights/accuracy are not yet approved.
- `OWNER-APPROVED` — WorldStage/Cherry has approved accuracy and use.
- `CLIENT-APPROVED` — client has approved use where required.
- `RIGHTS-VERIFIED` — usage/licensing rights are documented.
- `PRODUCTION-READY` — all applicable approval and rights gates are satisfied.

## WorldStage institutional facts

The following must be owner-confirmed before production copy treats them as canonical:

- legal entity / official business name;
- founding/history timeline (public sources have used both 2012 and 2014 language);
- canonical office/address/contact information;
- active team roster and titles;
- current solution/program catalog;
- partner/certification/licensing claims;
- current official payment and event channels;
- official privacy/DPO contact information.

## Programs

For every program intended for production display, record:

1. official title;
2. service family;
3. target audience;
4. challenge addressed;
5. intended outcome;
6. duration / delivery format;
7. modules / activities;
8. facilitator requirements;
9. safety requirements where applicable;
10. approved imagery;
11. approved evidence/outcome claims;
12. follow-up / sustainment model;
13. pricing/public-price status, if any;
14. owner approval date.

## Client stories and logos

No client story, logo, quote, testimonial, metric, case-study detail, internal history, or relationship claim may be promoted merely because it appears in a prototype, public website, sales deck, or AI-generated draft.

Each public client artifact requires, where applicable:

- client identity and approved public name;
- logo-use permission;
- challenge / discovery narrative approval;
- intervention description approval;
- outcome claim and exact evidence state;
- metric definition / baseline / follow-up / sample / calculation source;
- client sponsor confirmation;
- public marketing-use permission;
- expiry/review date or contractual restriction;
- source artifact location.

## Promotion gate

Production visual approval cannot be granted while required public-facing media remains `MISSING`, unless the owner explicitly approves a text/abstract-only release. Any such exception must be documented in the release manifest rather than inferred.
